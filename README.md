# Forge Fitness — Premium Gym Website

Multi-page, light-theme gym site: cinematic hero with in-hero navbar, pinned facilities story, horizontal equipment scroll, auto-scrolling reviews, gallery with lightbox, pricing with duration toggle, FAQ, and a contact page with a validated join form.


HTML5 + CSS3 + Vanilla JS · GSAP · ScrollTrigger · Lenis · **light theme only**

## Run
Serve the folder with any static server (e.g. `python -m http.server 5173`) and open `index.html`.
Needs internet for Google Fonts, GSAP/Lenis (CDN) and the Unsplash sample photos.

## Structure
- 8 pages: `index, about, facilities, programs, gallery, trainers, membership, contact` (.html) — generated by `python tools/build.py` (content lives in the data lists / section functions in that file). Bump the `?v=` on css/js links in build.py after changes to bust browser cache.
- `css/style.css` core · `css/responsive.css` breakpoints · `css/animations.css` initial states + reduced-motion
- `js/components.js` sliders, pricing toggle, testimonials, form
- `js/scroll.js` Lenis + nav · `js/animations.js` GSAP modules · `js/interactions.js` cursor, magnetic, drawer · `js/main.js` boot + `gsap.matchMedia`

## Before going live
1. **Images** — currently Unsplash samples. Put real photos in `assets/images/` and change `P` in `tools/build.py` (or edit `index.html`). The hero uses a **vertical crop on mobile (<768px)** and a **horizontal crop on desktop** via `<picture>`.
2. **Brand / contact** — replace "Forge Fitness", address, phone `+91 XXXXX XXXXX`, `hello@gymname.com`, the map embed and the domain (`example.com`) in `index.html`, `sitemap.xml`, `robots.txt`.
3. **Form** — set `FORM_ENDPOINT` at the top of `js/components.js` (Formspree / Web3Forms / your API). Empty = demo mode (simulated success).
4. **Transformations** — sliders use sample photos; use consented member photos.
5. Accent colour: `--acc` in `css/style.css`.

## Behaviour notes
- Desktop (≥1025px): Lenis smooth scroll, pinned facilities story, pinned horizontal equipment scroll, parallax, custom cursor, magnetic buttons.
- Tablet/mobile: no pinning; equipment + trainers use native swipe with scroll-snap; light fade/slide animations only.
- `prefers-reduced-motion`: Lenis and animations off, content fully visible.
- If the CDN scripts fail, the page stays readable (animation classes are removed).
